# Diplomski rad - Petar Lovrić - Household DR

## Setup Instructions

Follow these steps to set up the development environment and run the application:

1.  **Clone the Repository:**

    ```bash
    git clone https://https://github.com/KarnelutiA/PL_diplomski.git
    cd dim-app-2
    ```

2.  **Create a Virtual Environment:**

    ```bash
    conda create -n household-dr python=3.10
    activate household-dr
    ```

3.  **Install Dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

4.  **Run the Application:**

    Execute the main application script:

    ```bash
    python main_window.py
    ```
    This will start the Household DR application.
